15  Clean Code Principles

The exercises in this chapter concern the recommendations of PEP 8 and tools that support writing clean code. Tools are installed with the command pip install <name> (preferably in a virtual environment).

  1. Fix the names in the code below according to PEP 8 conventions (snake_case for variables and functions, UPPER_CASE for constants). Give the names a meaning that explains the role of each variable.
def F(L):
    S = 0
    for X in L:
        S += X
    return S / len(L)

A = [3, 5, 4]
b = F(A)
print(b)
  1. Fix the formatting of the code below according to PEP 8 (indentation, spaces around operators and after commas, blank lines, line length):
import math,random
def area(r):return math.pi*r**2
def main():
  for i in range(5):
    r=random.randint(1,10)
    print("r =",r,"area =",round(area(r),2))
main()

  3. Replace the “magic numbers” in the code below with constants that have readable names:

def final_price(price):
    if price > 500:
        price = price * 0.9
    return price * 1.23

  1. Add docstrings (compliant with PEP 257) to the module and to every function from exercise 5. Describe the arguments, the return value and the raised exceptions. Display them using help().

  2. Add type annotations (type hints) to the functions:

def average(numbers):
    return sum(numbers) / len(numbers)

def find_user(users, name):
    for user in users:
        if user["name"] == name:
            return user
    return None

Install the mypy tool and use it to check code in which the average function is called with a string instead of a list.

            if is_registered:
                return True
            else:
                return False
        else:
            return False
    else:
        return False

  1. The function below does too many things at once. Split it into smaller functions, each of which has a single responsibility (reading data, performing calculations, printing results):
def process():
    numbers = []
    while True:
        text = input("Number: ")
        if text == "":
            break
        numbers.append(int(text))
    even = [n for n in numbers if n % 2 == 0]
    odd = [n for n in numbers if n % 2 != 0]
    print("Even:", even, "sum:", sum(even))
    print("Odd:", odd, "sum:", sum(odd))

  3. Analyze the code below and list in a comment at least five problems related to the readability and quality of the code. Then rewrite it in a clean form.

def calc(d):
    # d - data
    r = {}
    for k in d:
        t = 0
        for i in d[k]:
            t = t + i
        r[k] = t / len(d[k]) if len(d[k]) != 0 else 0
    l = []
    for k in r:
        if r[k] >= 4.5: l.append(k)
    return r, l
