11  f-strings

  1. Define a variable name = "Anna" and a variable age = 28, then print them in a single sentence using an f-string of the form f"Name: {name}, age: {age}".

  2. Given the variable age = 28, write an f-string that evaluates the expression age + 5 inside the braces and prints the result in the sentence "In 5 years you will be: ...".

  3. Define a variable name = "Anna" and write an f-string that calls the name.upper() method inside the braces, printing the name in uppercase letters.

  4. Given the variable pi = 3.141592653589793, write an f-string with the :.4f specifier that displays the value of pi rounded to four decimal places.

  5. Define a variable loss = 0.00034521 and use an f-string with the :.2e specifier to print this value in scientific notation with two decimal places.

  6. Given the variable accuracy = 0.9534, write an f-string with the :.1% specifier that displays the accuracy as a percentage with one decimal place.

  7. Define a variable population = 38179800 and write an f-string with the :, thousands separator, printing the value in a readable format with commas.

  8. Given the variable revenue = 1543267.89, write an f-string that combines the thousands separator with a precision of two decimal places using the :,.2f specifier, and appends the currency PLN at the end.

  9. Define a variable population = 38179800 and use an f-string with the :_ specifier to print the value with underscores as thousands separators.

  10. Given the list of tuples metrics = [("Accuracy", 0.9534), ("Precision", 0.9211), ("Recall", 0.8876)], write a for loop that uses an f-string with left alignment :<12 to print the metric names in a 12-character-wide column, followed by their values in the :.2% format.

  11. Using the same metrics list, write a for loop with an f-string in which you apply right alignment :>15 with an asterisk * as the fill character, followed by a colon and the value in the :.4f format.

  12. Given the variable x = 42, write an f-string with the :^10 specifier that centers the number in a 10-character-wide field. Describe the role of the ^ operator here.

  13. Import datetime and define now = datetime.now(). Write an f-string with the :%Y-%m-%d format that prints the current date in the ISO standard.

  14. Using the same variable now, write two f-strings: one with the :%H:%M:%S format that prints the time, and another with the :%d %B %Y format that prints the date in the European format with the month name spelled out.

  15. Define the variables learning_rate = 0.001, epochs = 50 and batch_size = 32. Use the = debugging operator in an f-string (e.g. f"{learning_rate = }") to print the name and value of each variable.

  16. Given the variable loss = 0.0023456, write an f-string that combines the = operator with formatting, in the form f"{loss = :.4f}", and describe what will be printed.

  17. Given the variable train_acc = 0.9812, write an f-string that uses the = operator and the :.1% specifier to print both the variable name and its percentage value at the same time.

  18. Define a list values = [10, 20, 30, 40] and write an f-string in which you evaluate the expression sum(values) / len(values) inside the braces, printing the arithmetic mean.

  19. Given the variables model_name = "RandomForestClassifier", accuracy = 0.9534, precision = 0.9211, recall = 0.8876 and n_samples = 150000, write a multi-line f-string (in triple quotes) that formats a report of the model’s results. Use lines with {'='*50} as separators, right alignment :>8.2% for the metrics, and the :, thousands separator for the number of samples.

  20. Using the variables from the previous task, additionally compute f1 = 2 * precision * recall / (precision + recall) and extend the multi-line f-string with a row for the F1-score. Make sure that all metrics are uniformly right-aligned in an 8-character-wide column with the :.2% specifier, and that the whole report is surrounded by decorative lines generated by an expression in braces.
